## 说明
写给第一次买云服务器的人，按顺序做一遍即可。文中所有命令都单独成行、代码块不会跨页断开，可以整段复制。
文中出现的 IP、root 密码、API Key 位置都是占位符（形如 123.45.67.89、sk-你的密钥），执行时要换成你自己的。
